# JWST L2 Halo Mission Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the James Webb Space Telescope mission: Ariane 5 ECA from Kourou, direct transfer to Sun–Earth L2 with three corrections and the two-week deployment, L2 insertion, one circuit of a halo orbit held by station-keeping, seen in a Sun–Earth rotating frame.

**Architecture:** A new planner `src/halo.js` targets a CR3BP reference halo mapped into the real ephemeris with Newton-solved impulsive burns, integrating the whole flight with the existing Earth+Moon+Sun ODE; the app gains a `serot` frame, an L2 marker and a hand-drawn JWST model whose deployment is animated from the same table the planner turns into events. The launcher, site and pad follow the existing data-plus-drawn-look pattern.

**Tech Stack:** Vanilla JS engine (`src/*.js`, loaded by concatenation; tests in Node via `test/load.js`), three.js app (`app/*.js`, concatenated by `build.js`), headless-Chrome probe script for visual checks.

**Spec:** `docs/superpowers/specs/2026-10-28-jwst-l2-halo-design.md`

- Dates/figures pinned by the spec: launch `2021-12-25T12:20:00Z`, arrival `2022-01-24T19:00:00Z`, site 5.2392 N 52.7685 W, halo Az 350 000 km, station-keeping every 21 days, 1.05 circuits.

## Review Focus

1. A station-keeping solve that does not converge (Moon passing close to the transfer, or the reference halo far from a true ephemeris orbit): the planner must keep the best Δv, warn, and the craft must still stay in the 1.2–1.9 million km band — Task 4's test asserts the band for every node even when `sol.ok` is false.
2. The injection Newton starting from a parking orbit whose plane does not contain the L2 direction well (azimuth clipped by `azRange`): residual must still fall below tolerance — Task 4 asserts the arrival miss and that no warning mentions the injection.
3. The deployment animation evaluated before launch and after the last step (t outside the table): every pose must clamp to stowed / fully deployed — Task 6's check renders T−60 s and L+40 d.
4. The `serot` frame with no mission loaded or a mission with no Earth state (Mars missions): `seRot(t)` only needs the Earth's heliocentric state, but `chooseAutoFrame` must only pick `serot` for `profile === 'l2-halo'` — Task 5 checks a Mars scenario still auto-frames as before.
5. Deep-space distance in the minimap's `earth` view: the halo at 1.5 million km lies under the 1.8e6 cap, but the trail's `rmax` must not be set from the transfer's early points — Task 5 sets the view for `l2-halo` explicitly.

### Task 3: `src/halo.js` — rotating frame, L2 and the reference halo

**Files:**
- Create: `src/halo.js`
- Modify: `test/load.js` (ORDER), `build.js` (engine list)
- Test: `test/t_halo.js`

**Interfaces:**
- Consumes: `planetHelio('earth', t)` → `{ r, v }` heliocentric km, km/s; `BODIES.sun.mu`, `BODIES.earth.mu`, `BODIES.moon.mu`; `vunit, vcross, vsub, vadd, vscale, vnorm, vdot`; `integrate(f, t0, y0, t1, opts)` from `src/integrator.js`; `newtonSolve(F, x0, opt)`.
- Produces:
  - `const MU_SE = (BODIES.earth.mu + BODIES.moon.mu) / (BODIES.sun.mu + BODIES.earth.mu + BODIES.moon.mu)` (CR3BP mass parameter).
  - `seRot(t)` → row-major 3×3 `[x0,y0,z0, x1,y1,z1, x2,y2,z2]` whose columns are x̂ (Sun→Earth, unit), ẑ (unit of r × v of the Earth), ŷ = ẑ × x̂ — same layout as `emRot`.
  - `l2Gamma()` → γ (nondimensional distance of L2 from the Earth+Moon barycentre, root of the quintic `γ⁵ + (3−μ)γ⁴ + (3−2μ)γ³ − μγ² − 2μγ − μ = 0`, ≈ 0.01008).
  - `l2Point(t)` → geocentric ecliptic km `[x, y, z]` of L2: `x̂ · γ · |r_earth|`.
  - `haloCR3BP(azKm)` → `{ y0: Float64Array(6), T }` the periodic northern L2 halo in rotating nondimensional units (origin the barycentre, x toward L2, unit length 1 AU, unit time 1/n): Richardson third-order initial guess at the x–z plane crossing (x0, 0, z0, 0, ẏ0, 0), then differential correction on (x0, ẏ0, T/2) until the half-period crossing has ẋ = ż = 0 to 1e-9; cached by `azKm`.
  - `haloRef(t, tPhase0, azKm)` → `{ r, v }` geocentric ecliptic km, km/s on the reference halo at time t, with phase 0 (the point of the halo closest to the Earth) at `tPhase0`: evaluate the CR3BP orbit at phase `((t − tPhase0)/T_s) mod 1` (T_s the period in seconds from the Earth's mean motion `n = |r×v|/|r|²` at t), shift the origin from the barycentre to the Earth (`x − (1 − μ)`), scale by `|r_earth(t)|`, rotate with `seRot(t)`, and add the frame rotation to the velocity (`v_inertial = R·(v_rot + ω × r_rot)` with ω = n ẑ).
  - `haloPeriodS(t, azKm)` → period in seconds.
